--- Deliverable 7: Discussion ---
  Monotonicity check for lam >= lam* = 1.0000e-01:
    train RMSE strictly non-decreasing: True -> phrase: 'monotonically increase'
    test  RMSE strictly non-decreasing: True  -> phrase: 'monotonically increase'

  Discussion (P3): L1 regularisation (Lasso) produces exact zeros in the coefficient vector because the subdifferential optimality condition for a zero component j requires |Phi_j^T r| <= lam -- if the correlation of column j with the residual is small enough, the optimal solution is exactly w_j=0, i.e. the diamond-shaped L1 ball forces the solution to touch a corner/edge where some coordinates are zero. L2 regularisation (Ridge) only shrinks coefficients toward zero but generically never reaches exactly zero, because the L2 ball is smooth (no corners) and its gradient is proportional to w, becoming zero only if w=0 itself. As lam grows past lam* (lam*=1.00e-01 for Lasso), more coefficients are driven to zero, reducing model flexibility: the train RMSE tends to monotonically increase because the model cannot fit the data well, and the test RMSE tends to monotonically increase because the model underfits -- both curves rise beyond lam*, confirming that the signal is being penalised away along with the noise.
